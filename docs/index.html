进入 GenBox-Open 项目目录，用 Python 标准库启动体验。作品和历史版本保存在本机的 SQLite 数据库。

工程手记

教程里的网页，
应当留在教程里。

一篇 Markdown 教程可以包含完整的 HTML 示例。旧版粘贴入口看见完整网页就取出代码块，连同标题一起丢掉了正文。检查发布结果时，格式、标题和全文都要对得上。

在同一组手写回归用例中，三个字段同时匹配的用例从备份的 12/25 增至重构后的 25/25。这组样本用于复现具体输入边界。
